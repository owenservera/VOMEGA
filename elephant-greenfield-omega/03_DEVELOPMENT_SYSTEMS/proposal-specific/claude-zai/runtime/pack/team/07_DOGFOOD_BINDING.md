# DOGFOOD BINDING — how the team uses the pack's own protocol on itself (v0.2)

The pack proposes that cognition be **advisory**, that **Git/tests/raw output are truth**, that every claim carry a **basis stamp**, and that **recovery** come from a durable journal. The team protocol applies each idea to the team's own work. This file is the mapping, with an honest status per row.

## Dogfood rules

1. **The ledger is the memory.** If the platform loses conversation state between turns, the controller restarts from `ledger.jsonl`, `rounds/`, `evidence/`, `track-*/`. Anything not in those did not happen.
2. **No orphan claims.** A sentence in a closure report that cannot be traced to a ledger event or evidence file is deleted or downgraded to `SPECULATION`.
3. **The controller eats its own cooking:** every Controller step that changes state emits a ledger event first; if the emit fails, the step is not performed.
4. **Reproducibility check each round:** at CLOSE, `round.mjs check` re-runs selection from the manifest, verifies the ledger read-only and re-hashes the manifest, evidence and pack. The masters' track-main suites are re-run from a clean checkout of the tags, and their outputs are recorded in the closure report.
5. **Using Track B's machinery inside the team is not allowed to contaminate Track A:** the Controller may use the kernel as *tooling* (ledger, capsule, citation checks), but must not route Track A arms' work through ECP consults.

## Drills (run once by R2, again by R6; D2–D9 are also exercised by the team tests)

| Drill | Procedure | Pass condition |
|---|---|---|
| D1 Lost turn state | Start a turn with no memory; run `round.mjs status .` | Position and next step reconstructed from the ledger; no repeated work |
| D2 Tampered ledger | Flip a byte in a **copy** (or use `fixtures/sample-round-k2`); `ledger.mjs verify` and Cockpit ingest | Both report `{ok:false, seq:9, reason:'hash mismatch'}` with the same `head_before_break` |
| D3 Leak | Plant another arm's canary (or only its 24-hex part) in an arm dir; `isolation.mjs report` | Arm tainted; `select.mjs` disqualifies it |
| D4 Seed escape | Modify a seed file or commit in seed/; `fence check` | `SEED_MODIFIED` / `SEED_GIT_CHANGED` |
| D5 Unblinded evaluator | Edit an eval file after `evalkit commit` | `evalkit join` refuses; INCIDENT `INDEPENDENCE` |
| D6 Claim inflation | Arm claims `LIVE_RUN` with a missing file, or "all tests pass" when acceptance fails | `evalkit audit` flags it (evidence 0); Cockpit Audit flags it; the ledger refuses an evidence-less `LIVE_RUN` event |
| D7 Tie handling | Two arms within the margin | `TIE_CARRY_BOTH`; next-round brief extends both |
| D8 Label inflation (new) | Put `MEASURED-CAPABLE` in a closure report whose census says otherwise | `round.mjs check --closure` reports `CLOSURE_REPORT_FIRST_SCREEN_MISSING_OR_EDITED` |
| D9 Early oracle (new) | Emit `ORACLE_UNSEALED` before `ARMS_SEALED` | Lint `UNSEAL_BEFORE_ARMS_SEALED`; `round.mjs seal-arms` refuses afterwards |

## Bridging to the pack's experiment

The team program is a **practical rehearsal and partial execution** of `outputs/claude/EXPERIMENT.md`: Track A ≈ arms A/B/F; Track B ≈ E1-S (and E2-S from R3). It does **not** replace the experiment's replications, blind external graders, or the context-pressure stage; it produces the first honest data, the operating habits, and the Cockpit that the larger study will reuse. Treat its numbers as pilot data at best.
