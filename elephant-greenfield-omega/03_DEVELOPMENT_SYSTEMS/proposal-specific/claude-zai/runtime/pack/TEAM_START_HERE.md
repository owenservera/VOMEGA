# TEAM_START_HERE

This pack now has two layers:

1. **The protocol and research pack** (original files + `outputs/claude/`): Elephant 0/1/2 design, ECP v0.2 kernel, experiment design.
2. **The team program** (`team/`): a turn-based, two-track, rounds-and-arms process that builds Prompt Fanout Mini and a Cockpit web app **using that protocol on itself**.

**To launch the team on z.ai:** open `ZAI_FIRST_PROMPT.txt`, paste it, attach this zip (**never** attach `OWNER_ONLY_*` files). Round 0 is two turns. Turn A: capability census, frozen manifest, four arms, isolation checks, sealed evidence; it stops at `AWAITING ORACLE KEY`. You then send `unseal C1 <key>` from `OWNER_ONLY_ORACLE_KEYS.txt`, and turn B evaluates against the hidden oracle, selects, assimilates, builds the Cockpit and closes.

**What to expect:** the labels on page one are computed by tools from evidence files. If the platform cannot run isolated, independent arms, the report says **PROCESS REHEARSAL** and selection uses mechanical scores only; Track B's cognitive value stays untested under a scripted consultant. That is the intended honest outcome, not a failure.

Read first if you want the logic before running: `team/01_TEAM_CHARTER.md` → `team/02_ROUND_PROTOCOL.md` → `team/04_EVALUATION_AND_SELECTION.md`.
