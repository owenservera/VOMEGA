# Decisions requiring explicit operator disposition

Before E1: permission to transmit selected source corpora to chosen provider; excluded-path scanner results; live adapter proof; shared exact baseline SHA; worker concurrency count; resource cap; whether an Elephant may propose patches; review identities.

Before E2: first Elephant quality and maintenance results; validated session resume/rotation; independent provider session identity; max per-node queue length; cross-consult fanout=2; stale response policy; cross-boundary manifest overlap; measured value of independent second node vs same-pack fresh reviewer.

Before making any architecture permanent: blind task-grade results, costs, defect escape data, scale of improvement, novelty search, user preference for future service scope, and net maintenance cost. Do not silently make untested design assumptions binding.

## Retention defaults (proposals)

Transaction traces 7 days or until scorecard sealed; retain sanitized request metadata and test artifacts needed for reproducibility; do not collect raw confidential prompts. Raw model transcripts local, restricted, retention-limited. Durable domain notes require approval with source-bound validity predicates.
