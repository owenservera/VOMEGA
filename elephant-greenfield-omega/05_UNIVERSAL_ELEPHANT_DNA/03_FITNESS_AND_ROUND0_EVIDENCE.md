## Six cross-use-case tests (candidate initial battery)

| Fitness probe | Stimulus | Observable pass condition | Key falsifier |
|---|---|---|---|
| F1 Self-inventory | Hide, exclude, duplicate, change and supply source items | Correct read/eligible/excluded/unknown accounting with exact anchors | Claims all material understood from a transport receipt |
| F2 Resource literacy | Supply incomplete provider and controller telemetry, change model/content mix | Correct units, provenance and UNKNOWN/ESTIMATED distinctions | Fabricated available tokens or cost; bytes/4 asserted as actual usage |
| F3 Peer exchange | Route bounded cross-domain inquiry through real separate contexts | Proven causal request/result, matching basis, source anchors and finite deadline | Invented peer knowledge, unchecked relay or nonterminating calls |
| F4 Knowledge invalidation | Mutate shared contract while one node is resident | Detect mismatch, mark impacted knowledge, reconcile or safe fallback | Old contract returned as fresh current source |
| F5 Reconstruction | Kill source session, rebuild from released pack | Fresh session passes withheld competence queries; no false hidden-memory persistence | Restores transcript but loses knowledge or preserves stale basis |
| F6 Adaptive method | Record real bottleneck and test competing response policies | Controlled matched comparison with total costs and independent quality evidence | 'Winning' method increases errors or hides expensive failed calls |

Apply each probe to three domains: codebase understanding, semantic product cognition and an unrelated document/research task. Cross-over models, source order and blind evaluator when feasible. Real Elephant identities and actual separate contexts must be demonstrated for E1/E2; E0 remains the matched control.

## Round 0 facts that constrain genome claims

- **Scope isolation:** separate Task-tool model contexts were observed, but deliberate cross-workspace writes succeeded. Filesystem confinement is an OS/tool permission obligation, not a property guaranteed by cognitive DNA. Do not claim the coding boundary is enforced by 'only talk to Product Elephant'.
- **Staleness:** one small frozen fixture reported 0/3 stale assertions with mechanical gate vs 2/3 without (about 0.8131 ms gate time, 0 extra model calls). Candidate supports DNA-16, not proof for all domains.
- **Context rotation:** when all three fixture files changed, incremental rotation used 4,049 vs 3,602 tokens for rebuild and failed three changed-fact checks. Falsifies 'delta is always cheaper', not all incremental designs. Directly informs DNA-07/10/19.
- **Token accuracy:** bytes/4 underestimated one provider-specific six-call content ladder by ~65–70%; approximately 2.43 characters/token was observed locally for that pack/model, not a global conversion. Informs DNA-04.
- **Provenance:** initial strict source citation anchors were 2/7 before format/verification changes; a later consult reached 7/7 strict. Inform DNA-15 with external quote/anchor checks.
- **Structured output budget:** two live consults failed to produce complete JSON under a 128-output-token cap. Separate generation budget from resident source budget.
- **Transport:** A2A experiment measured roughly 1.14x offline latency and 3.4–3.5x wire bytes vs native ECP; protocol cancellation did not halt model spend. Do not mandate either transport as genomic law.
- **Real session economics:** SDK usage sometimes reported prompt/output tokens, but controller and money cost were UNKNOWN. E0 cost includes worker inference, not zero.
- **Pack continuity:** a clean-room handoff reproduced 30/30 fixture tests but exposed missing evidence/manifest details. Rebuildability includes complete evidence/access, not only rerunnable code.
- **Parallelism:** genuine overlap varied across controller turns (6/6 pairs vs 1/6). Count observed overlap, not announced fan-out.
- **Claims still unproven:** historical semantic corpus 100% per-main cognitive reading; full integrated Semantic Product Elephant Group; validated Product→Harvest→Developer code change; native Tauri MVP; comparative overall Elephant productivity gain.

## Fitness reporting

Every result must include `gene_id(s)`, `probe_id`, `use_case`, `arm` (including E0), `source_epoch`, `model/harness`, `test_fixture_hash`, `evaluator`, `observed_behavior`, `expected_behavior`, `grade` (PASS/FAIL/LIMITED/UNKNOWN), measured vs estimated vs unknown resource counters, exact reproducible evidence, and next falsifier. Missing executions are NOT_RUN, not passes.

Maturity is **candidate → probed → independently verified in scope → challenged cross-domain → proposed universal**; acceptance as constitutional invariant requires explicit owner decision. Published status is not certification.
