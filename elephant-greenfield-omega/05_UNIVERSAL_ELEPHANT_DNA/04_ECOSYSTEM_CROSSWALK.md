# 04 — Universal Genome × Elephant Ecosystem × Semantic Factory

## Three dimensions that must not be conflated

1. **Genome (universal)**: observable capabilities inherited by any Elephant, if validated — identity, introspection, memory discipline, peer exchange, source trust and learning.
2. **Phenotype (role-specific)**: domain competencies or duties layered onto the genome — Product semantic cognition, Harvest archaeology, research methods, integration review, user-owned personal knowledge, etc.
3. **Realization (implementation)**: a chosen model, context packaging strategy, file allocator, persistent session, cache, transport, CLI, kernel, bus, storage engine, UI or protocol adapter. These are experiment variables, not genetic law.

Likewise E0/E1/E2 are experiment *numbers of genuine cognition resources*, not species or genome editions. E0 is a necessary control and is not required to exhibit Elephant self-competencies. The universal DNA should make E1/E2 independently testable, not invalidate the no-Elephant baseline.

## Round outcomes are not genomic definitions

The seven MVP rounds (Windows text box, provider/account natural setup, command/visual parity, simulated three-target fan-out, authorized live webapp realization, adaptive UI+Wiki, integrated verified release) test Semantic Factory productivity. The parallel semantic library gates test off-MVP historical source retention. Neither is a prerequisite for an Elephant in an unrelated domain to inherit DNA-01 through DNA-20.

The initial frozen complete-source read is an **ingress benchmark** for each independent main, not an endpoint for the permanent Elephant ecosystem and not evidence of comprehension. Afterward, semantic library and Product Elephants maintain source freshness through continuous or demand-triggered reconciliation.

## Multiple separate authority boundaries

- Product Elephant **directs the work** of Harvest Elephants and issues scoped coding work packets **within the existing project task authority**. That direction is a role policy, not an Elephant gene.
- Harvest historical knowledge cannot become source-native operational truth without reconciliation and independent proof.
- Workers obtain instructions through Product gateway but must independently inspect allowed current source/test output and escalate contradictions.
- OS-enforced file scopes, owner-controlled live effects, reviewed Git integration and Ratchet gates are external governance. Universal cognition does not confer filesystem rights.
- DNA-driven process changes, new tools, protocols or context allocation methods begin as isolated experiments and receive no product deployment permission merely because an Elephant proposed them.

## Sharing across ongoing independent labs

Treat genome v0.1 as a **new optional research cohort** when introducing it to the existing general A/B/C Z.ai lab, the O1 proposal-specific lab, Claude's lab or the Semantic Factory. Do not retroactively amend frozen prompts, benchmark conditions, archived results or active experimental source bases. Append genotype version and source digest to each later trial so the effect of DNA requirements can be measured.

Cross-lab artifacts flow as immutable, independently verifiable publications. Compare candidate gene requirements **across** conflicting architectures. If a gene cannot be satisfied without a chosen special-purpose technology, attempt a simpler portable implementation before classing that technology as universal. Preserve falsifiers, competing approaches and rejected genes.
