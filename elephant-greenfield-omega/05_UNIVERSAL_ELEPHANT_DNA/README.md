# Universal Elephant DNA — Cross-Use-Case Seed v0.1

**Status: CANDIDATE GENOME / DESIGN RESEARCH, 2026-10-11. Not ratified as a constitutional product rule, not an implemented runtime, not a new active Z.ai session.**

This is a shared conceptual seed for what **any Elephant must be able to demonstrate**, independent of domain, model, memory capacity, transport, implementation or product. It combines the 20 proposed traits from the October 11 discussion with bounded evidence from the Round 0 Z.ai workspaces and the existing Semantic Factory. It does **not** prescribe 20 software modules or replace any experiment architecture.

**Core thesis:** An Elephant is a persistent, reconstructable, bounded cognitive entity with an operationally inspectable self-model; source/evidence-grounded knowledge; deliberate context ingress, recall and egress; peer interoperability; and evidence-led method improvement. No claim of subjective self-awareness is intended. The model's claim about its state is not telemetry.

## Authority and compatibility

- **No silent baseline mutation.** [00_CORE_BASELINE](../00_CORE_BASELINE/README.md) remains the frozen baseline for existing E0/E1/E2 studies; use this DNA seed as a separately identified input cohort. Existing results remain attributable to their original cohorts.
- **No mandatory architecture.** The [O1 ECP design](../protocol/02_ECP_V0_SPEC.md), [Claude proposal](../02_ARCHITECTURE_PROPOSALS/claude/README.md), other designs, and the [Semantic Factory](../03_DEVELOPMENT_SYSTEMS/semantic-factory-zai/README.md) are alternative or use-case-specific realizations to compare, not constitutional implementations of the DNA.
- **Product truth remains external.** Source/accepted Git revisions, owner authority, runtime evidence and independent tests outrank Elephant opinions; an Elephant cannot generate consent or grant itself write access.
- **Support services are allowed.** Many genes require an external instrument, ledger, runtime or coordinator to produce trustworthy measurements. The inherited obligation is to consume, interpret, report and act consistently on those records, not to hallucinate inaccessible internals.
- **Do not canonize gene count.** Candidate genes can merge, split, be rejected, or become optional. A gene becomes universal only after discriminating tests across multiple genuinely different use cases.
