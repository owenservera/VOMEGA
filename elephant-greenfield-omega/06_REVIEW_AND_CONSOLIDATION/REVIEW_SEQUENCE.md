# R0–R8: Multi-Round Research, Analysis and Streamlining Sequence

**Scope:** `elephant-greenfield-omega/` at pinned Git HEAD plus explicit source and artifact references. This is a sequential *decision-gated* analysis program with parallel independent reviewer lenses inside rounds. It is NOT a replay or a reset of Z.ai's original R1 experiment arms, and the round labels here are `AUDIT-R0 ... AUDIT-R8`, never product milestones or live Z.ai rounds.

## North-star question

Which minimum set of product contracts, research truth rules, artifact interfaces and navigation paths must be made unambiguous **now**, and which documents/implementations should remain independent, be condensed, be moved behind historical indexes, or be archived after a verified cutover? Optimize **fresh-agent time-to-correct-action, evidence retrievability and independently accepted useful product**, not file count or LOC.

## Common operating protocol

**Immutable inputs:** capture Git commit/tree SHA, `mvp/NORTH-STAR.md` blob SHA, frozen benchmark fixture/hash, exact proposal versions, publication snapshot references and external bundle availability/privacy. Catalog only what is actually accessible; inaccessible ZIPs remain PRIVATE_EXTERNAL / NOT_REPLAYED. New evidence must state MEASURED / ESTIMATED / UNKNOWN, observation source and epoch.

**Independent reviewer lenses:** (A) product/operator UX + MVP v0.5; (B) architecture independence + Elephant DNA falsifiability; (C) code/experiment/evidence reproducibility; (D) adversarial contradictions, dependency and archive safety. Fan-out only on independent bounded research questions. Reconcile with a separate judge, preserving minority positions and raw evidence. A single reviewer must not certify its own code. Do not fake child IDs or parallelism.

**Per-round outputs:** `AUDIT-Rn/manifest.json` with input hashes, participants and real execution basis, `findings.md` citing file paths/lines or hashes, `decision-deltas.md`, `open-questions.md`, and a review acceptance record. For code claims, attach exact commands/exit statuses/log hashes and independent replay; for claim-only findings, mark AUTHOR_ANALYSIS. Do not publish these as a capability-pack turn unless they were produced by an actual top-level development track under the existing [every-turn contract](../01_EXPECTED_OUTPUTS/02_EVERY_TURN_PUBLICATION_CONTRACT.md).

**Decision labels:** FORMALIZE_NOW / CANONICAL_KEEP / EXPERIMENTAL_KEEP / LEGACY_ACTIVE_COMPAT / ARCHIVE_CANDIDATE / PRIVATE_EXTERNAL / SUPERSEDED_WITH_REDIRECT / UNKNOWN. Add `basis_sha, owner, depended_on_by, evidence, proposed_destination, migration_gate, rollback_ref`. Labeling is non-destructive; relocation requires a separate reviewed change.

## Required R2 capability map

Use explicit values `PRODUCT_NORTH_STAR / BENCHMARK_SIMULATED / CODE_PRESENT_UNVERIFIED / MOCK_REPLAYED / LIVE_INDEPENDENTLY_PROVED / NOT_RUN / OUT_OF_SCOPE`. Record capability identity separate from its realization and proof. Minimum v0.5 clusters: command-first floating interaction; guided clarification and visual interpretation; user master-folder/workspaces; per-provider/account/model/session registration and isolation; browser commands; discovered provider capabilities; attachments and independently configured fanout; local history/repeat; contextual wiki; appearance/drawers/layout; initial empty infinite 3D development shell. **No automatic response ingestion, cross-model synthesis, or monitoring dashboard**; real account integrations require explicit permission and actual observed outcomes. Packaging is deferred in the *development shell* but belongs to the eventual Windows MVP.

## Minimal R3 contract topics — formalize semantics, not implementation

1. Source precedence: owner product intent vs frozen research seed vs source, fixtures, actual runtime witness; explicit amendment and cohort change.
2. Identifier namespace: Provider / Account / Model / Session / Workspace / Command / Execution / Pack / Proposal / Elephant / Cohort are not interchangeable.
3. Canonical action meaning: NL → typed plan; ambiguity alternatives, user preview, consent and no silent capability or permission promotion.
4. User-owned persistence: master-folder selection, local identity, event history, references and version/change rules. JSON first remains permissible.
5. Pack identity and every-turn full-index publication: source/hash, maturity vs runtime state, immutable refs, dependencies, false-claim downgrade, reviewer status and recovery.
6. Evidence and measurement: MEASURED / ESTIMATED / UNKNOWN, observable witness, simulated vs live, offered vs read vs tested source coverage, no manufactured token counters.
7. Elephant lifecycle/self-model: basis epoch, retrieval vs retained cognition, freshness, state uncertainty, rotation/rebuild disclosure, privileges and peer claims; architecture neutral.
8. Handoff/consumption: code availability, private artifact custody, reproducibility, internal/external trust, licensing and safe source sanitization.
9. Archival semantics: last live consumer, immutable archive pointer, digest, alias/link redirects, restoration test, reversible approved migration.

## Success is reduction in uncertainty, not prettier folders

Score independent correct-answer rate for the 8 cold-start questions, broken references, duplicate sources of authority, unreproducible claims, protected path violations and verified operator effort. LOC and count of moved files are secondary diagnostics only. Record `NOT_MEASURED` if no true R0 baseline or counters exist.

## Stop / branch / rollback gates

- R0 and R1 may proceed read-only immediately. R2–R6 can run as separate sub-investigations but must not silently alter existing R1 experiment conditions.
- A critical conflict may trigger an earlier minimal documentation fix with the same evidence/gate discipline.
- If a review round yields no likely decision change, stop instead of manufacturing eight rounds of output.
- No archive move before verified consumer migration and hash-verified rollback; use one reviewed main integration, with short-lived task worktrees only.
- Do not introduce a new universal bus, forced agent framework, storage architecture, 20-gene implementation mandate or MVP release shortcut by editing this document.
