# 00 — Canonical Core Baseline

**Purpose:** the shared, source-grounded Elephant/Greenfield Ω problem statement that every architecture author and every independent development system receives **unchanged**. This folder is about the shared research question and non-negotiable truth/safety limits, not one implementation.

Start with [vision and scope](01_VISION_BOUNDARIES_AND_EPOCHS.md), [frozen product seed](02_GREENFIELD_OMEGA_SEED.md), and [authoritative context map](03_SOURCE_MAP_AND_TRUTH_POLICY.md). Everyone may cite this common material. No architecture proposal, framework choice, microservice map or team structure belongs in this baseline.

Versioning rule: freeze each benchmark seed at a declared hash. Changes to baseline are explicit, dated, compatible/incompatible, and force affected measurements to be labelled as a **new cohort**, not silently compared with the old cohort. Live Round 1 baseline is not rewritten.

The initial source documents remain available in ../01_MASTER_CHARTER.md and ../02_GREENFIELD_OMEGA_PRODUCT.md and the original proposal-specific protocol/ folder. Historical research is linked in ../reference/SOURCES.md. The shared baseline below restates the research question without declaring that the earlier authored ECP is the only solution.
