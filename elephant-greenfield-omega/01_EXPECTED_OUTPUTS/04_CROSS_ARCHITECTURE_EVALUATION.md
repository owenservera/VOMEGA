# Comparison Across Authors, Labs, Packs and Systems

## Two independent axes
1. **Architecture source:** initial proposal (ours/Claude/other), distinct from who implements it.
2. **Development habitat:** unrestricted general Z.ai lab vs dedicated Z.ai instance for *one* proposal. The general lab still has A/B/C internally; each proposal lab may also run isolated competing refinement teams.

A proposal's apparent superiority may be due to the developer runtime, extra token budget, different source evidence or leakage. Record both axes to distinguish these explanations.

## Comparable gates
- Freeze shared Ω seed and benchmark fixture/hash per cohort; label intentional variants.
- Set comparable model, budget, test, environment and run constraints, or disclose mismatches.
- Retain fresh E0 challenger and measure full E1/E2 context residency/refresh/coordination cost.
- For each lab compare accepted product capability, correctness, defects, isolation, source freshness, replay, resource spend, maintenance and portable pack quality.
- Score **pack capability** separately from **track reference assembly** and **cross-proposal composition**.
- Independent judge maintains holdouts and verification. C may operate benchmarks but does not sign self-scores.
- Publish exact sample sizes, unclear causality and failed/null experiments. Never infer performance from code volume, package count or aesthetic dashboard quality.

## Fair innovation
Architectural anchors are initial hypotheses, not truth. Proposal-specific experiments optimize locally while preserving a traceable baseline and deviations; unrestricted lab explores unrestricted. External standards/tools may be tested by any lab. No one gets to secretly reuse other current-round code. Data shared from a completed experiment must retain provenance, release conditions and source epoch.

## End-state selection
Select the best actually tested assemblies and reusable pack portfolio contributions, including mixed-proposal compositions that beat the strongest single proposal. It is acceptable for no proposed architecture to win unchanged. Discovery remains open.
