# Other Independent Proposal Authors

Create one uniquely identified child directory **per actual submitted unique design**. No anonymous blended 'consensus proposal.' Capture author/model/session as verified or unknown, immutable proposal version, initial core baseline hash, author's independently submitted vision/architecture/assumptions/falsifiers, and honest revisions.

Each proposal can have its own independently started full Z.ai development environment only after source is actually submitted and seeded. Placeholder folders are not working architectures or launched sessions.

All proposals obey 01_EXPECTED_OUTPUTS mandatory turn publication. Keep design authors, general exploratory builder, and per-proposal dedicated builders as **separate roles with separate contexts**.
