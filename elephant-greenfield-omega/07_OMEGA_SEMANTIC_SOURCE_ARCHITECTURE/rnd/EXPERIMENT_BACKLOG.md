# Semantic SDK — first combined experimental backlog

## T1 — Structural Plain Reading variants
Test sentence split, voice, clause order and account naming beyond cosmetic search. Compare over identical fixture with round-trip/injectivity/completeness, hostile ambiguity, human comprehension and cost. No source changes to frozen fixture without a new cohort.

## T2 — A2A `omega-contract`
Review primary A2A/MCP specs before drafting a versioned extension with command/reading/digest, grammar revision, evidence basis, derivation trace, ambiguous alternatives and labels. Test malformed/missing extensions, Unicode control characters, stale revisions, signatures and native-path equivalence. An HMAC test is not a JWS Agent Card signature.

## T3 — Minimal kernel primitives
Compare Fuchsia CML, WASI Component Model/WIT, seL4, AIOS, Letta and Temporal, then justify a minimal replaceable contract/runtime core. Resist transport and storage commitments in universal DNA.

## T4 — Prior art / clear explanation
Check full patent claims and original primary technical references before any novelty or FTO assertion. Distinguish findings from legal opinions.

## Cross-cutting release blockers
- Silence-free ambiguity resolution is distinct from merely attaching an ambiguous list.
- Bind digest to exact canonical command and authoritative execution context; handle drift and TOCTOU.
- Unicode normalization, confusable/bidi rejection and payload/route separation.
- Independent clean-room replay and held-out cross-system comparison.
- Every top-level development turn publishes all candidate, negative, blocked, retired and unchanged capability packs using the *existing* Elephant Lab publication contract.
