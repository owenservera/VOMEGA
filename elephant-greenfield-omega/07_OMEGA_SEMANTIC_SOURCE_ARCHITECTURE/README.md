## Candidate SDK boundary

- ΩSL declarative semantics and deterministic Plain Reading are research candidates.
- Proof obligations: command/reading round-trip, injectivity, completeness, a binding checked before execution.
- Natural language and model interpretations do not grant execution authority.
- Provider, Account, Model, Session, Capability, command and source epoch are distinct identities.
- Proposed projections: runtime registry, reading/recognition grammar, verification, wiki, agent interop. No projection has production approval.
- A2A omega-contract is an interoperability profile under research, not a new transport.
- Numeric claims are MEASURED, ESTIMATED, or UNKNOWN and require witness and cohort details.
