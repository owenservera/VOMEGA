## SDK safety

Provider != Account != Model != Session. Command digest != display/consent binding != actual execution permission. An ambiguous READY state blocks side effects. Any input edit or source/fixture/account/session/policy revision invalidates approval. Repeat/history creates a NEW preview and requires a NEW confirmation. Quoted provider names are payload unless a declared grammar slot says otherwise. Do not grant rights from LLM prose or A2A extensions.
