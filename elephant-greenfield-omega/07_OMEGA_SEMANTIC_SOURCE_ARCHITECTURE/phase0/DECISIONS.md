# Architectural decisions and risks

1. **Preserve original sources.** The exact archive was available. Selected source files and all benchmark scaffolds were reviewed for secrets, personal identifiers, side-effecting code and license declarations. Fixture names are synthetic, selected Python uses stdlib/local files, no credential literals found. Original hard-coded author-machine comparison paths are not executed. Historical patch authorship and content remain private archive evidence. This bounded inspection is not an automated secret audit of every historical patch. No upstream license was present; source attribution retained without relicensing.
2. **Python reference bridge first.** Both actual implementations replay. Building a purported TS port would hide the largest remaining portability experiment. Browser client is TS, stripped to checked-in JS by Node; core remains Python. No full TS typecheck ran.
3. **Ambiguity blocks execution.** Run A has 803 hostile mismatches, including 758 wrong READY, all flagged in the observed set. A flag is not a permission gate. The wrapper requires a server-enumerated explicit choice and fresh confirmation. A second parser or future candidate cannot issue execution rights.
4. **Independent finite oracle.** `oracle.py` independently reconstructs six READY readings/constraints instead of asking the author renderer to certify itself. Mutation and candidate tests falsify altered readings, missing consequences, changed targets, omitted fields and forged identity. This proves a bounded checker, not universal grammar correctness; author-derived partial states are labelled as such.
5. **Separate identity and authority.** Domain-separated semantic hash, exact display binding and opaque one-use permit have different roles. Trusted state checks occur again at dispatch. Atomicity is within one Python process; durable replay protection is absent. Receipts are returned by value and retained internally, not a tamper-proof audit log.
6. **Data-only intake now.** We can grade actual response artifacts without running untrusted source. Candidate code execution remains blocked pending a real sandbox. Integrity proves bytes, not honesty; public-output conformance is not implementation certification.
7. **No benchmark promotion.** B1–B4 remain NOT_RUN competitions. Run A-generated comparisons bias the cohort toward A's grammar. Original A and B latency metrics use different harness paths and cannot support a speed ranking. Generation wall times and scorer latencies are measured; asymptotic complexity is not benchmarked. Inspection suggests A loops over template regexes and diagnostic account phrase alternatives; B uses ordered recognition branches. Both need matched growth tests for long inputs and expanded registries.
8. **Source epochs are conservative.** Any covered source change invalidates previews, even if semantically harmless. This costs reuse but prevents silent stale compilation. Per-field precise spans, generated docs, typed contracts and declaration evolution remain research targets.
9. **Handoff is an experiment map.** Existing computer missions remain historical/provisional. Phase 0 motivates a safety-first referee, portable compiler, declaration-change twin, ambiguity UX, and context/relay economics. Owner review must precede frozen prompts.

Highest risks: unrestricted-language intent correctness; server/frontend trust; in-memory lifecycle and resource bounds; candidate isolation; unavailable blinded data; untested Windows/browser behavior; absent human comprehension evidence; license status for wider redistribution. All are explicit limitations, not reasons to weaken gates.
