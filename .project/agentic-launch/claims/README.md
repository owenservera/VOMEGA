# Development Agent Claims

This directory is the lightweight live register for development-agent work.

Read [../DEV-AGENT-REGISTRATION.md](../DEV-AGENT-REGISTRATION.md) before creating a claim.

Rules:

- one claim file per meaningful worker/session;
- register before substantive repository work;
- use a unique readable filename such as `YYYYMMDD-HHMM-work-agent.md`;
- keep the claim high-level;
- update only on material changes;
- close or pause it before the session ends;
- material outcomes/blockers also get a concise handoff in `.project/COMMONS.md`;
- registration is coordination, not authority or proof.

Do not create a central active-claims table here. Separate files reduce write collisions during parallel work.

Use [CLAIM-TEMPLATE.md](CLAIM-TEMPLATE.md) as the minimum shape.
