# VOMEGA documentation archive

Historical content is retained here to preserve evidence, rationale and reconstructability **without making fresh agents read it as current instruction**.

## Current authority lives outside this folder

- fresh worker: `/AGENTS.md` → `.project/SITREP.md`
- product core: `/seed-docs/README.md`
- whole-program map: `.project/META-TRACKER.md`
- D1: `.project/deliverables/D1-START-HERE.md` + Ratchet
- PM: `.project/pm/README.md`
- live proof: `.project/live-proof/`

## Archive groups

- `project-history/` — old SITREP/Commons/meta reviews/roadmap status and incorporation history.
- `agentic-launch/` — first-wave lanes, prompts, model routing, manifests, closed claims and handoffs.
- `pm-bootstrap/` — PM seed/corrections/setup/ZCode-team/recon/reviews superseded by the operating PM data/model.
- `seed-process/` — bootstrap/tool/old workstream/Elephant process documents removed from default product reading.
- `tooling/` — Dev-machine, Orca, KMem and related harness setup/research.
- `ratchet-history/` — dated Ratchet review/integration history.

Archive records are evidence and may contain instructions that were valid when written. They do **not** override current source/tests/evidence, owner decisions, seed invariants or current operating docs.

Some original paths remain as short tombstones because machine-readable provenance or historical links name them directly.

- `roadmap-reference/` — the 2026-10-05 74-task first-release roadmap, workstream cards and proof traceability retained as reusable historical decomposition.
