## Reading the labels

- **D1–D2:** concept largely known; implementation/proof dominates.
- **D3:** bounded design comparison is useful.
- **D4:** full design cycle expected before commitment.
- **D5:** frontier/load-bearing design; use independent alternatives, falsifiers and prototypes.
- **M1:** functional truth; **M2:** functional core; **M3:** integrated/robust; **M4:** generalized/adaptive; **M5:** state of the art.

Criticality rank is **within the program only**. It is not a ranking of programs and does not select work.
